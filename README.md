# 🐍 Snake Cyberpunk

> **Grow. Survive. Dominate.**

A retro arcade game reimagined with a cyberpunk aesthetic, built in **JavaScript** using **p5.js**.

## Features

* 🎨 10 unlockable skins
* 🪙 Bits economy system
* 💎 Common, Rare & Legendary fruits
* 🛡 Energy shield
* ✨ Particles & screen shake
* 💾 Automatic save
* 🔊 Original cyberpunk sound design
