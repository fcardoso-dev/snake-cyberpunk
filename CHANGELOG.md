# Changelog

Todas as mudanças importantes do Snake Cyberpunk serão registradas aqui.

---

## [1.1.0] - Achievement Update

### ✨ Adicionado
- Sistema de conquistas com popup animado
- Tela de estatísticas do jogador
- Registro permanente de partidas, frutas, escudos e Bits
- Tela de boot da FSC Studios
- Novo botão "Estatísticas" no menu principal

### 🎨 Melhorado
- Menu principal totalmente redesenhado
- Botões neon unificados com efeito hover
- Painel Wallet + Recorde + Skin reorganizado
- Interface mais limpa e cyberpunk

### 🐛 Corrigido
- Cobra travando ao iniciar partida
- Funções duplicadas de skins removidas
- Hover incorreto entre Skins e Estatísticas
- Organização geral do mousePressed()
